# Code of conduct

Be respectful and constructive. Critique code and ideas, not people. No harassment,
discrimination, or personal attacks in issues, pull requests, or discussions.

Security research shared here is for defence. Don't use this project to coordinate attacks
on systems you aren't authorised to test.

Maintainers may edit, lock, or remove content and block participants who violate this.
Report concerns through the private channel described in `SECURITY.md`.
